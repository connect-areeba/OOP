# CDN

This project demonstrates the application of **Object-Oriented Programming (OOP)** principles and **Gang of Four (GoF) Design Patterns** through a real-world **Content Delivery Network (CDN)** system.

## Design Patterns Implemented
- Proxy Pattern
- Iterator Pattern
- Observer Pattern
- Strategy Pattern

## Project Structure
- **Application Overview** – Introduction to the CDN system
- **Design Pattern Implementation** – C++ implementations of each pattern
- **UML Diagrams** – Class diagrams for the implemented patterns
- **Presentation** – Project presentation slides

## Technologies
- C++
- Object-Oriented Programming
- UML
